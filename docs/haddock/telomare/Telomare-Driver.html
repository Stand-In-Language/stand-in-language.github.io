Parse and compile a module set, keeping the sizing results. Every problem comes back as text a user can act on rather than as an exception, so callers decide how to report it.

Each module is parsed under its own name, so the locations in diagnostics can say which file a term came from.

compileModulesWith :: SizingOption -> [(String, String)] -> String -> Either String (SizingReport, CompiledExpr) Source #

compileModules at a chosen sizing budget. Tests use a deliberately tiny budget to reach the budget-exhaustion path without waiting for 65536 abstract unrollings.
