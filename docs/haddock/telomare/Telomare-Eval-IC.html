Telomare.Eval.IC

Description

Driver glue for the interaction-combinator runtime (IC): the admission gate and the guided evaluator, in the shape the eval loop (evalLoopCore) consumes.

The net's correctness rests on EAL typability (EAL), so a driver must not hand it a program without the certificate — that is admitIC, run once per compiled program. Iterations only ever apply the program to data input, which the certificate's virtual application of main already covers, so one admission holds for a whole session; the capture layouts riding on the granted plan feed the runtime's guided closure-duplication strategy (ealCaptureLayouts).

admitIC :: CompiledExpr -> Either String ICPlan Source #

The admission gate, from scratch: certify the compiled program on its own account and grant a plan only on success. The refusal is rendered for a user — the whole-program verdict first, then the bodies that failed on their own account (dependency-failure cascades are elided when a root cause is present). A driver that compiled through compileMainReporting already holds this inference's product and reads the same admission off it with programPlan instead of paying for it again here.
