Telomare.Artifact

Description

A compiled program on disk, so that sizing happens once.

Sizing a Prelude-heavy program costs minutes and several gigabytes, and it produces the same answer every time: it runs the program over a symbolic input, so nothing about a particular run can change it. Paying that on every invocation is pure waste. `--compile` writes the sized program, its per-site iteration counts and its rendered certificate to a .telc file; running that file skips parsing, typechecking, resolving and sizing entirely.

The encoding is a tag byte per node, written by hand rather than derived. CompiledExpr is a fixpoint of three small functors, so this is a short function; deriving it instead would mean either a Read instance (there is none, and the Show1 instances are not round-trippable) or orphan Binary instances for a type this module does not own.

A hash of the sources is stored so a stale artifact can be recognized. It is a warning and never a refusal: an artifact is expected to outlive the checkout it came from, and the sources may not be there at all.
