Telomare.Machine

Description

The shared small-step abstract machine: composable step algebras over any IR built from the base functors. Each *Step handles one functor (basic pairs, stuck/defer forms, aborts, superpositions, indexed inputs, unsized-recursion markers) and defers the rest to the next handler, so the sizing pass, the reference evaluator and the partial evaluators all assemble their interpreters from the same parts.
