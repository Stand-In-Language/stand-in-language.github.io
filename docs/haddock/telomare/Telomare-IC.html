Description

An interaction-combinator runtime for CompiledExpr.

This is the "abstract algorithm" flavor of sharing-graph reduction: duplicator nodes carry labels minted fresh at every template instantiation, there are no boxes or brackets at runtime, and dup pairs annihilate only with themselves. That rule set is not sound for arbitrary terms — a duplicator reaching a copy of itself through a term that duplicates its own duplicator computes garbage — and EAL typability (EAL) is the classical sufficient condition under which it is correct. The EAL pass is therefore this runtime's admission certificate: the only analysis output the runtime's *correctness* depends on is that verdict (no levels, no sharing plan). Templates are keyed by the same content hash that keys the DeferMap (deferLift), so per-hash CodeGuidance addresses templates directly; guidance-driven choices must remain advisory (strategy, never meaning).

Telomare maps onto interaction agents unusually cleanly because it has no binders: Env is the only variable, so a compiled Defer body is a static net template whose env interface is a single wire. That wire fans out through a splitter tree built from the body's projection-path usage — the same fact CodeGuidance publishes as cgUsage: each used env component is delivered on its own wire (ICSplit takes a pair apart in one interaction), unused components are erased at the highest point, and duplication happens only where a path is genuinely used more than once — exactly where the analyzer charges contraction. Every Defer becomes a Template plus an ICRef pointer node; copying a ref is copying a pointer (the code table exists at runtime), and only the instantiated body's wiring is ever duplicated structurally.

The semantics mirror the reference evaluator (Possible basicStep/stuckStep/abortStep) rule for rule:

  • SetEnv (Pair (Defer d) e) instantiates d's template with env e.
  • A gate applied to a scrutinee yields one of the reserved selector defers (doLeft/doRight); branch selection is then ordinary application of a projection body, and the unselected branch is erased.
  • Abort applied to Zero yields the reserved identity defer; applied to a pair it becomes an Aborted value that consumers propagate. Aborted values surface as AbortRunTime only if they survive into the result, matching the reference checkError.

Interaction nets are confluent, so although this runtime fires redexes in worklist order rather than the reference's evaluation order, final results agree on terminating programs; termination itself is what the EAL certificate promises. Bodies that are exactly equal share one template (the content hash narrows candidates; an exact Eq check decides, since the hash is blind to the FunctionIndexes of nested defers). Each ICRef node carries its own site's FunctionIndex, so readback reconstructs the defer value the reference evaluator would produce — defer equality is by index, which makes naive whole-value dedup observable.

One discovered subtlety governs the error rules: the reference evaluator, being ordinary lazy Haskell, is effectively call-by-need — a stuck redex sitting in a discarded gate branch is never forced, and compiled sizing machinery really does leave ill-shaped applications in dead branches. The net instead fires every redex it instantiates, so an ill-shaped interaction must produce an ICStuckV poison value rather than abort the run: erasure discards it silently (the net's analogue of an unforced thunk), and only a stuck value surviving into demanded output reports ICStuck. The same speculation means the net eagerly evaluates bounded dead code the reference skips (a cost, not a correctness issue), and dead code that diverges shows up as fuel exhaustion rather than being skipped.

Agent kinds. Slot 0 is always the principal port; value kinds face their consumer with it, consumer kinds face the value they demand.

Compilation

envUsage :: CompiledExpr -> Map [Step] Int Source #

Env occurrences of a body per projection path (outside nested defers, which are closed over their own env). The keys mirror the analyzer's usage view (envUsageL) and its guidance (cgUsage): the steps directly applied to the occurrence, innermost first — the order they descend the env value.

envPathOf :: CompiledExpr -> Maybe [Step] Source #

The projection path this term applies directly to Env, when it is nothing but a projection chain over Env; Nothing as soon as anything else intervenes. The Just cases are exactly the occurrences envUsage counts, so producer and consumer of the env wiring agree by construction.

isolatedNet :: ICM a -> ICM (a, IntMap Node, Int) Source #

Run a net-building action against a fresh empty net, restoring the current one afterwards; returns the built nodes and their label count.

deferHash :: CompiledExpr -> Either String (Digest SHA256) Source #

The content hash of a defer value, computed by the code path that keys the DeferMap (deferLift) — lifting a bare defer value leaves a lone reference carrying its hash — so templates and per-hash CodeGuidance share one namespace by construction. The hash names the lifted body (nested defers appear as refs), so it is blind to FunctionIndexes.

compileDefer :: CompiledExpr -> ICM (TemplateId, FunctionIndex) Source #

Compile one Defer value into a template, or reuse the template of an exactly-equal body already compiled (the hash narrows candidates; Eq decides, since the hash ignores nested defer indexes and index-blind sharing would be visible to readback). The site's own FunctionIndex is returned for the caller to keep on its ref node.

compileBody :: CompiledExpr -> ICM Int Source #

Build a body's net: allocate its env splitter tree, walk the term, and wire the result to the boundary node.

envCopies :: Port -> Int -> ICM [Port] Source #

The ports producing each copy of one value. The incoming value is delivered at src: to an eraser when no copy is needed, straight through for one, through a dup chain otherwise.

envWiring :: Port -> Map [Step] Int -> ICM (Map [Step] [Port]) Source #

Build the env splitter tree for one usage map: each used projection path gets its own delivery wires, produced by descending the env value through ICSplit agents. Duplication happens only where a path is directly used more than once, or used and also descended past (the analyzer's whole-and-part contraction); components no used path needs are erased at the highest point.

takeEnvWire :: [Step] -> ICM Port Source #

Take the next delivery wire for one env path.

compileTerm :: CompiledExpr -> ICM Port Source #

Compile one term, returning the port its value is delivered from. Projection chains applied directly to Env compile to nothing: their component arrives pre-split on its path's wire.

instantiate :: TemplateId -> Port -> Port -> ICM () Source #

Splice a fresh copy of a template into the net: envSrc produces the env value, resultDst awaits the body's value. Dup labels are offset by a fresh base, so every instantiation's dups are distinct from every other's — the discipline the EAL certificate makes sound.

stuckAt :: String -> String -> Port -> [Port] -> ICM () Source #

An ill-shaped interaction: the consumer's result becomes a stuck value and the listed leftover operands are erased. Stuckness must be a value rather than a thrown error because the reference evaluator is lazy — a stuck redex whose result is discarded is no error at all there, and the eager net must agree observationally.

rule :: Int -> ICKind -> Int -> ICKind -> Maybe (ICM ()) Source #

The oriented rule table: rule n nk m mk fires the interaction with n in the first role, or Nothing if this orientation has no rule (the caller then tries the flip). Every rule gathers the peers it needs before deleting or rewiring anything.

materialValue :: Port -> ICM (Maybe ICKind) Source #

The kind at a delivery port, when it is a materialized value (its principal faces us); Nothing while the wire still awaits a computation.

dupPlanFor :: Port -> ICM (Maybe CapShape) Source #

The capture layout to duplicate a closure by, when the pair's head is a materialized code pointer whose hash has published guidance.

dupRegion :: Label -> CapShape -> Port -> ICM (Port, Port) Source #

Duplicate the value region at a delivery port by its capture shape: structurally copy what is already a materialized constructor (pairs, zeros) or code pointer, and place a fan — with the plan's label, as the generic cascade would — at every frontier: unmaterialized values, shared or foreign nodes, and positions the shape does not vouch for. Correct for ANY shape: the shape only chooses where copying is attempted, the materialization checks decide, so wrong guidance can cost performance but never meaning.

describeValue :: Int -> Int -> ICM String Source #

A bounded structural sketch of the value at a node, for error messages: pairs descend, leaves print their kind, in-flight machinery prints as itself.

passThrough :: String -> Int -> Int -> Int -> ICM () Source #

Forward the value m to the consumer n's result slot, deleting the consumer: projections of Zero, and Aborted values passing through.

awaitShape :: String -> Int -> Int -> ICKind -> ICM () Source #

An applied gate or abort must inspect its operand's shape: replace the apply with a shape-awaiting node facing the operand.

projectPair :: String -> Int -> Int -> Int -> Int -> ICM () Source #

Project one component of a pair to the consumer's result and erase the other.

Readback

readback :: Port -> ICM CompiledExpr Source #

Read a normalized value net back into syntax. A ref reads back as the defer of its template's body under its own site's index, so results compare equal to the reference evaluator's (defer equality is by index) even when sites share a template.

Abort messages are data; anything else truncates to Zero, mirroring the reference evaluator's message truncation.
