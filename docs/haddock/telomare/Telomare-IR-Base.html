Telomare.IR.Base

Description

The shared functor vocabulary of the compiler. Telomare's IRs are not independent grammars: each one is a composition of the base functors defined here (BasicExprF, StuckF, AbortableF, LamTermF, HighTermF), glued together by the *Base embed/extract classes. The pattern synonyms are polymorphic over those classes, so one synonym (e.g. PairB) works at every stage of the pipeline.
